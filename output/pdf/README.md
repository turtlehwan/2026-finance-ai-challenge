# 내부 검토용 PDF

이 폴더의 두 PDF는 내용과 시각화를 빠르게 검토하기 위한 **편집본**이다.
DAKER가 제공한 공식 `첨부 1`·`첨부 2` 양식을 사용한 문서가 아니므로
**공모전 제출 파일로 사용하지 않는다.**

## 공식 제출본 생성 경로

1. [`../hwpx/README.md`](../hwpx/README.md)의 절차에 따라 팀장·팀원 실명을
   로컬에서만 주입한다.
2. `output/private/submission/`에 생성된 공식 양식 HWPX 두 파일을
   한컴오피스 또는 한컴독스에서 연다.
3. 표의 쪽 나눔, 글자 겹침·잘림, 팀 정보를 전 페이지에서 확인한다.
4. 한컴에서 각각 PDF로 내보낸다.
5. 그 PDF 두 개와 배포 URL을 DAKER 제출란에 등록한다.

## 이 폴더 파일의 용도

- 기획서·기능명세서의 문장과 표 검토
- 제출 문서에 들어갈 도식의 시각적 검토
- 팀 내부 피드백 및 발표자료 재사용

정본 텍스트는 `docs/planning-proposal.md`와 `docs/feature-specification.md`,
공식 양식 공개 안전본은 `output/hwpx/`에서 관리한다.
