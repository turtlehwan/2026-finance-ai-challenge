# 실제 공식 약관 데이터와 provenance

이 디렉터리는 예선 MVP가 어떤 공식 원문을 읽고 구조화했는지 재현하기 위한
출처 보관소다. 개인 보험증권·진료기록·청구 이력은 들어 있지 않다.

## 포함 데이터

- `fss-standard-terms-20260715.pdf`: 국가법령정보센터에서 내려받은
  `보험업감독업무시행세칙 [별표 15] 표준약관` 현행본
- `fss-standard-terms-20250611.pdf`: 버전 비교용 과거 시행본
- `manifest.json`: 출처 URL, 시행일, 적용면, SHA-256, 데이터 성격

우체국보험 상품 약관은 원문을 저장소에 복제하지 않고 공식 PDF URL과 해시만
manifest와 코드에 기록한다. KB손해보험 상품목록은 상품코드·약관 링크를 확인하는
공식 카탈로그 출처로만 연결한다. 각 보험사 PDF의 이용조건은 실제 사용 시 별도로
확인해야 한다.

## 제품에서의 사용 방식

1. 상품코드·계약일로 공식 판매기간/시행기간을 확인한다.
2. 질병·상해보험 표준약관에서 정의·지급·면책·청구·지급절차 핵심 조항을
   구조화한다.
3. 상품별 약관과 표준약관을 함께 검색하고, 원문 URL·페이지·시행일을 결과에
   공개한다.
4. 신규 문서가 생겨도 자동으로 운영 인덱스를 변경하지 않고, 내부 회귀 테스트와
   사람 승인 뒤 별도 배포 절차에서 반영한다.

화면의 `100%` 지표는 이 공식 원문의 법적·지급 정확도를 의미하지 않는다. 고정된
합성 fixture에 대한 계약/안전성 회귀 통과율이며, 실제 보험사 지급 데이터나 고객의
기존 청구 이력은 평가 범위가 아니다.
