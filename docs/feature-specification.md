# 2026 금융 AI Challenge 기능명세서 — 보험금 길잡이 Agent

> 문서 상태: 예선 제출용 최신본
> 기준일: 2026-07-31
> 작성 원칙: 배포 URL에서 실제 동작하는 기능만 기재한다. 미구현 기능은
> 본문 범위에 포함하지 않는다.

## 1. MVP 구현 범위

현재 배포된 MVP는 심사용 비식별 합성 사례 3종을 사용해 다음 범위를
구현했다.

- 손목 골절, 오래된 계약, 면책 조건 사례 선택
- 사례의 사고·진단·계약 정보 표시
- 단계별 Agent 분석 진행 상태 표시
- 부족한 사실에 대한 사용자 추가 질문
- 답변을 반영한 제한 상태 결과 생성
- 사건부터 다음 행동까지의 근거 경로 표시
- 필요 서류·보험사 문의 질문 Action Pack
- 공식 조회·청구 채널 연결
- 큰글씨 모드와 모바일 반응형 UI
- PolicyOps 변경 조항 검토·승인 시연

현재 결과는 프론트엔드 합성 사례와 서버 규칙 API를 연결한 동작형
프로토타입이다. 실제 약관 PDF 파싱, 사용자 문서 업로드, 실제 Agent 그래프
실행과 React Flow 시각화는 이 문서에 아직 구현 완료 기능으로 기재하지
않는다.

## 3. 사용자 이용 흐름

1. 사용자가 배포 URL에 접속한다.
2. 상단의 큰글씨 버튼으로 글자 크기를 선택한다.
3. Interactive demo에서 세 합성 사례 중 하나를 선택한다.
4. `이 사례 분석하기`를 누른다.
5. Agent가 근거를 확인하는 단계와 진행률을 본다.
6. 추가 질문에 `예`, `아니오`, `잘 모르겠어요` 중 하나로 답하고 제출한다.
7. 답변을 반영한 담보별 상태와 이유를 확인한다.
8. 근거 경로를 따라 사건·담보·지급·면책 관계를 확인한다.
9. Action Pack에서 준비 서류와 보험사 문의 질문을 확인한다.
10. 공식 채널에서 실제 조회 또는 청구를 진행한다.

## 4. AI 및 데이터 처리 방식

### AI 역할

현재 MVP 서버는 사례 ID와 사용자 답변을 입력받아 사전 정의된 증거 구조와
안전 규칙으로 결과를 생성한다. 화면은 Agent의 목표 지향적 진행, 정보 부족
시 질문, 답변 반영, 근거 검토와 행동 계획을 시연한다.

### 입력·출력

- 입력: 합성 사례 ID, 추가 질문 답변
- 출력: 담보별 제한 상태, 근거와 한계, 근거 경로, 필요 서류, 확인 질문
- 사용 데이터: 코드에 포함된 비식별 합성 보험·진료 사례

### 개인정보·민감정보

현재 공개 MVP는 실제 개인정보를 입력받거나 저장하지 않는다. 회원가입이
없으며 합성 사례 선택 정보만 브라우저에 저장할 수 있다. 실제 사용자 문서
업로드 기능은 현재 구현 범위에서 제외되어 있다.

## 5. MVP 검증 방법

### 검증 절차

1. 배포 URL에 접속한다.
2. `손목 골절` 사례를 선택하고 `이 사례 분석하기`를 누른다.
3. Agent 분석 후 질문에 `아니오`를 선택해 제출한다.
4. 골절진단비가 `확인 권장`, 상해수술비와 입원일당이 `가능성 낮음`으로
   표시되는지 확인한다.
5. 근거 경로와 Action Pack이 나타나는지 확인한다.
6. `면책 함정` 사례에서 `잘 모르겠어요`를 선택한다.
7. 보상 조항만으로 결론을 내리지 않고 `정보 필요` 또는 `확인 불가` 상태가
   나타나는지 확인한다.
8. 큰글씨 버튼과 모바일 화면에서 동일한 4단계 흐름이 유지되는지 확인한다.

### 계정과 실행 환경

- 테스트 계정: 필요 없음
- 권장 브라우저: 최신 Chrome, Safari, Edge
- 권장 환경: JavaScript 활성화, 데스크톱 또는 모바일

### 예상 결과

- 질문 답변 전에는 결과를 확정하지 않는다.
- 면책 사실을 모르면 지급 가능성을 단정하지 않는다.
- 모든 결과에 이유·한계·다음 행동이 함께 표시된다.
- 최종 지급 여부와 확정 금액은 서비스가 제시하지 않는다.

### MVP 제한사항

- 현재 약관과 진료 문서는 합성 사례로 구성되어 있다.
- 실제 PDF 업로드·OCR·공식 약관 검색은 아직 배포본에 연결되지 않았다.
- 보험사의 청구 이력·지급심사·확정 금액을 조회하지 않는다.
- 실제 보험금 지급 여부는 보험회사가 결정한다.
