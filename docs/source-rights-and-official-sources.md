# 보험 공식 출처 조사와 이용 리스크 판단

이 문서는 “공식 웹사이트에 공개되어 있다”는 사실과 “원문을 자유롭게
복제·재배포·학습할 수 있다”는 권리를 구분하기 위한 내부 기준이다. 법률
자문이 아니며, 상용 서비스나 실제 개인정보 처리를 시작하기 전에는 변호사와
개인정보·금융 규제 검토를 별도로 받아야 한다.

민간 손해보험사 상품목록은 예선 MVP의 필수 근거가 아니다. 제품·문서·manifest에서
제거했다. 특정 기업의 상표나 공시 페이지를 사용하지 않아도 우체국보험과
국가법령정보센터의 버전·원문·페이지 근거만으로 데모를 재현할 수 있다.

## 2. 출처별 이용 원칙

### 국가법령정보센터·금융감독원 표준약관

저작권법 제7조는 헌법·법률·명령·조례·규칙 및 국가·지자체의 고시·공고 등을
보호받지 못하는 저작물로 열거한다. 국가법령정보센터도 이에 해당하는 법령정보와
법제처가 저작재산권을 전부 보유한 저작물은 별도 허락 없이 이용할 수 있다고
안내한다. 다만 사이트의 편집·주석·데이터베이스와 제3자 자료는 별도 권리일 수
있으므로, 공식 원문과 사이트의 이용정책을 함께 확인한다. 필요한 조항을
구조화해 출처·시행일·페이지와 함께 인용하고, 표준약관만으로 개별 계약의
지급 여부를 확정하지 않는다.
현행본과 과거본을 혼합하지 않으며, 서비스에는 상품별 약관이 우선한다.

### 우체국보험 약관·공시

공공데이터포털 API의 이용조건과 우체국보험 공시실의 문서별 조건을 각각
확인한다. API가 약관 URL을 제공한다는 것은 공식 문서 위치와 메타데이터를
확인할 수 있다는 뜻이지, PDF 전체를 자유롭게 재판매하거나 대량 재배포할
수 있다는 뜻은 아니다. 현재 MVP는 상품명·상품코드·적용기간·해시와 공식
URL을 저장하고, 필요한 조항만 근거로 보여준다. 결과 근거는 우체국와이드건강보험
2112·2504와 우체국온라인입원수술보험 2112의 짧은 조항 인용으로 제한한다.

### 공공데이터포털·심평원 데이터

질병정보서비스는 공공데이터포털에 이용허락 범위가 “출처표시 제1유형”으로
표시되어 있다. 따라서 출처를 표시하고, 제공기관의 제3자 권리 고지와 API
이용조건을 함께 준수한다. KCD 코드가 보험금 지급요건을 자동 충족한다는
표현은 사용하지 않는다.

### 손해보험협회·보험개발원 안내

청구서류와 공식 실행 경로를 안내하는 참고자료로 사용한다. 협회 안내를
특정 보험사의 지급 약속이나 서비스의 지급 판정으로 바꾸지 않는다. 문구는
짧게 요약하고 원문 링크를 제공한다.

## 3. 공개·재사용에 대한 법적 판단

### 결론

현재 예선 MVP처럼 “출처 링크 + 짧은 사실 요약/필요 조항 + 적용일·페이지·해시
공개 + 지급 불확정 + 공식 채널 연결”로 제한하면 위험을 상당히 줄일 수 있다.
그러나 공개 페이지라는 이유만으로 민간 약관 PDF의 전체 복제, 상업적 재배포,
모델 학습, 로고·상표 사용이 자동으로 허용되는 것은 아니다.

공공누리는 저작물에 표시된 유형에 따라 조건이 달라진다. 제1유형은 출처표시
후 상업적 이용·변경이 가능하지만, 제2~4유형은 상업적 이용 또는 변경이
제한된다. 기관 페이지에 공공누리 표시가 없으면 원문 전체를 자유이용할 수
있다고 추정하지 않는다. 법령·행정규칙의 공적 성격과 별개로 국가법령정보센터
사이트의 데이터베이스 이용조건, 편집·주석·서식의 권리를 확인한다.

### 금융 규제 경계

금융소비자보호법은 금융상품판매업 등의 등록과 광고·대리·중개를 규율한다.
따라서 서비스는 보험상품 추천·비교판매·가입 유도·보험금 지급 확정·청구
대행을 하지 않고, 사용자가 제공한 사건과 공식 문서의 근거를 정리해 공식
보험사 채널에서 확인할 질문과 서류를 안내한다. 제휴 수수료, 계약 체결 버튼,
특정 보험사 우대 문구를 추가하면 법적 성격이 달라질 수 있으므로 상용화 전
별도 검토가 필요하다.

### 상표·기업명

공식 출처를 식별하기 위해 “금융감독원”, “우체국보험”, “손해보험협회”라는
출처명을 사실대로 쓰는 것은 필요하지만, 해당 기관의 승인·제휴·추천으로
오인될 수 있는 로고·브랜드 락업·“공식 서비스” 표현은 사용하지 않는다.
민간 보험사 자료는 해당 기업의 상표·약관을 제품 브랜드처럼 전면에 내세우지
않는다. 이 판단이 KB 자료를 제거한 이유 중 하나다.

### 개인정보·건강정보

진단명·질병코드·진료기록은 개인정보 보호법상 건강 관련 민감정보가 될 수
있다. 예선은 전량 합성 문서를 사용한다. 기본 텍스트 파싱은 원본을 서비스의
파일시스템·데이터베이스에 저장하지 않고 마스킹 결과만 반환한다. 사용자가
`AI 보조 문서 이해`를 켠 경우에는 PDF·이미지가 Cloudflare Workers AI 문서 변환에
전송되므로, 외부 처리 고지와 명시적 동의를 요구한다. 범용 LLM에는 원문이 아닌
마스킹된 미리보기만 전송한다. “서버에 저장하지 않는다”는 문구만으로 처리
의무가 없어지는 것은 아니다.

## 4. 예선 제출 시 적용할 체크리스트

- 모든 근거 카드에 기관명·문서명·시행일/적용기간·페이지·원문 URL을 표시한다.
- 공공 API는 데이터셋 페이지의 이용허락 범위와 출처표시 문구를 기록한다.
- 민간 보험사 PDF 전체를 새로 수집·재배포하지 않는다. 이번 제출물에서는
  특정 민간 보험사 카탈로그를 사용하지 않는다.
- 표준약관·상품약관의 짧은 조항 요약과 필요한 인용만 사용하고, 지급 확정·예상
  금액·보험사 대리 표현을 금지한다.
- 상용 공개 전에는 법률·개인정보·금융 규제 검토를 다시 수행한다.
